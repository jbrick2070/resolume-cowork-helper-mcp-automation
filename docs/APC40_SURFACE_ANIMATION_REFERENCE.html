APC40 surface animation reference - restrained set (decided)

Interactive visual target for the V3/V4 clip refinement. Idle loops run live; click any control to fire its trigger/latch state. Source of truth for geometry, timing, palette, and the V3-vs-V4 tier split: APC40_SURFACE_ANIMATION_CONCEPTS.md (same folder). Note for V3 coders: the value readouts shown here on knob, faders, and crossfader ("→ 107", "█ 127", lit tick counts, tip segment) are V4 Wire-only elements - V3 static art must be value-agnostic per the roadmap section of the doc. Geometry constants shared by V3 art and V4 patches: 15 arc segments on 270°, 11 fader ticks, 0.04u silhouette insets, state palette red #e83c2e / green #3cd05a / amber #f5aa22 / cyan #28c8dc / blue #5a78ff; chassis #b51d35 never inside a control.
