## Text sources (all public domain or fair use)

- **Executive Order 9066** (Feb 19, 1942) — US government, public domain
- **"Instructions to All Persons of Japanese Ancestry"** posted notice — US gov, PD
- **CWRIC "Personal Justice Denied"** report findings — US gov publication, PD/CC0
- **Camp senryu translations** from NPS Tule Lake article — US gov publication, PD
- **Short fair-use excerpts** from Portland Assembly Center senryu collection
- **Factual place names, dates, camp names** — not copyrightable
- **Widely-used Japanese community phrases** (shikata ga nai, gaman, kodomo no tame ni)

## Surface (98 shortcuts — every physical control)

Same layout as all React packs: grid = text pads, track select = fire a column
(scene), scene launch = kill a row, activator/solo = mute/isolate, faders = row
presence, clip stop = comp FX toggles, device knobs = FX + per-row glow, track
knobs = SIZE / GLOW / BLOOM / HALO / THRESH / WARP / RIPPLE / DRIFT.

LED colours match on-screen palette: gold (Title), red (Signal), white (Voice),
amber (Archive), violet (Ground).

## Install

1. `compositions/Res React Nisei.avc` -> `Documents\Resolume Avenue\Compositions\`
2. `controllers/APC 40 MK II - Nisei v1.xml` -> `Documents\Resolume Avenue\Shortcuts\MIDI\`
   (select for input **and** output in Preferences > MIDI)
3. General Prefs: **"Update clip panels on external triggers"** ON.
4. Feed Avenue audio: Ground breathes on bass, Voice shimmers on mids, Signal
   snaps on highs. With no audio, sweep floors keep everything visible.

## The pitch

100% native Text Block generators — no media files, no FFGL, no plugins, ~1 MB.
Loads instantly on any Resolume rig. The VJ fires pads and the testimony composites
in real time. Three decks tell the arc of the community: Little Tokyo before the
war, the camps and the poetry that survived them, and the return — Nisei Week
revived, redress won, the next generation carrying the story forward.

The last pad on the last deck says OKAERI. Welcome home.
