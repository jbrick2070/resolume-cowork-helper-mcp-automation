TRACK KNOBS 1–8 · per pad

  • 1 GAIN (size)
  • 2 PHOSPHOR (glow)
  • 3 EXCITE (brightness)
  • 4 PAPER (fade) / TRIG (threshold) on FFT cells
  • 5 HALO (bloom)
  • 6 QUAKE H
  • 7 QUAKE W
  • 8 SWEEP

SURFACE — ALL 149

  • ▸ Track Select 1–8 — fire a whole reading (column)
  • ▸ Scene Launch 1–5 — lift the pen (clear that row)
  • ▸ Clip Stop 1–8 — the instrument rack (8 comp FX)
  • ▸ Activator 1–5 / 6–8 — channel power / row lamps
  • ▸ Solo 1–5 / 6–8 — isolate / verdict spotlights
  • ▸ Rec Arm 1–5 / 6–8 — ROLL a row / force states
  • ▸ A/B row — the diagonal walk (8 presses = a look)
  • ▸ Pan / Sends / User — TONE / BARS / SNOW
  • ▸ ◀ ▶ + Bank < > — instrument dial (decks)
  • ▸ ▲ ▼ + Nudge — paper feed (columns)
  • ▸ Faders 6–8 — TONE / BARS / SNOW trims
  • ▸ Tempo knob — RELATIVE calibration screw (CAL DIAL)
  • ▸ Footswitch — THE STOMP (hold for RGB split)

AUDIO — WHAT MEASURES WHAT

  • ~ EKG trace — narrowed bass, +9 dB, 150 ms snap
  • ~ Richter trace — bass swell, 1200 ms fall
  • ~ VU columns — bass / mids / highs, one band each
  • ~ Polygraph needles — the mids (the voice)
  • ~ Geiger stamps — highs, +9 dB, 100 ms clicks
  • ~ PILOT strobes — one per deck, bass-gated, floor 0
  • ▸ External FFT — set Avenue's audio input device
Five fictional instruments, all pointed at the same room: whatever the music does, the machines report it. 185 pads are native Text Block rasters (block-element typography); per deck one SNOW (Static), one PILOT (Stroboscope) and one CAL DIAL (Shaper). Preset APC 40 MK II - Telemetry v1 — select it for input and output so the pads light. Mirrored buttons (marked in _control_map.tsv) are deliberate: the same cue under a second finger.
